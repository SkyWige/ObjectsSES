# Список на месяц

Простое мобильное приложение для Android и iOS. В список можно добавлять строки и отмечать их галочкой как выполненные. Раз в месяц приложение напоминает снять галочки, а сами строки остаются. Есть белая и тёмная тема.

## Установка на Android

[Скачать ObjectsSES.apk](https://github.com/SkyWige/ObjectsSES/releases/latest/download/ObjectsSES.apk)

Откройте файл на телефоне и разрешите установку из этого источника. Новая сборка появляется автоматически после каждого изменения в ветке `main`.

## Как работает список

- Строка бывает с галочкой или просто текстом. Вид выбирается над полем ввода и меняется в подробностях строки.
- Нажмите на квадрат, чтобы поставить или убрать галочку. Рядом со строкой появится дата отметки.
- Нажмите на строку, чтобы открыть подробности. Там можно изменить текст и его цвет, добавить заметки и фото или удалить строку.
- В самом списке длинный текст сокращается до двух строк, а вместо вложений показано их количество.
- Тема сначала следует настройкам телефона. Кнопка вверху экрана переключает её вручную.

## Виджеты

На Android доступны два виджета: «Список» и «Сводка». В «Списке» можно ставить и снимать галочки прямо на главном экране, а нажатие на текст открывает приложение. Виджеты следуют теме телефона. На iOS виджетов нет.

## Как работает напоминание

- Напоминание приходит того же числа, в которое список был создан. Например, для списка от 5 ноября это 5 декабря, 5 января и так далее.
- Если в месяце нет такого числа, напоминание будет в его последний день: 31 января, затем 28 февраля, затем 31 марта.
- В этот день в 10:00 приходит уведомление с кнопкой «Снять все галочки», если есть хотя бы одна галочка и уведомления разрешены.
- В приложении кнопка «Снять все галочки» доступна всегда, когда есть галочки. До даты напоминания она просит подтвердить нажатие.
- Сами по себе галочки не снимаются. Дата следующего напоминания показана вверху экрана.

Данные хранятся только на телефоне.

## Запуск

Нужны Node.js и приложение Expo Go на телефоне.

```bash
npm install
npm start
```

Отсканируйте QR-код из терминала в Expo Go. Телефон и компьютер должны быть в одной сети. Уведомления и виджеты проверяйте в собранном APK.

Версия Expo Go должна поддерживать Expo SDK 58. Если приложение не откроется, соберите установочный файл через [EAS Build](https://docs.expo.dev/build/introduction/):

```bash
npx eas-cli@latest build --platform android
```

## Проверки

```bash
npm test
npm run typecheck
```

Логика списка находится в `src/checklist.ts`, экраны — в `App.tsx` и `src/DetailScreen.tsx`, уведомления — в `src/reminder.ts`, фото — в `src/photos.ts`, виджеты — в `src/widgetBridge.android.tsx`.
