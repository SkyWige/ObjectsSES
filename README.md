# Список на месяц

Простое мобильное приложение для Android и iOS. В список можно добавлять строки и отмечать их галочкой как выполненные. Раз в месяц все галочки снимаются, а сами строки остаются.

## Установка на Android

[Скачать ObjectsSES.apk](https://github.com/SkyWige/ObjectsSES/releases/latest/download/ObjectsSES.apk)

Откройте файл на телефоне и разрешите установку из этого источника. Новая сборка появляется автоматически после каждого изменения в ветке `main`.

## Как работает сброс

- Сброс происходит в полночь того же числа, в которое список был создан. Например, список от 5 ноября сбрасывается 5 декабря, 5 января и так далее.
- Если в месяце нет такого числа, сброс будет в его последний день: 31 января, затем 28 февраля, затем 31 марта.
- Если приложение было закрыто в день сброса, галочки снимутся при следующем открытии.
- Дата следующего сброса показана вверху экрана.

Данные хранятся только на телефоне.

## Запуск

Нужны Node.js и приложение Expo Go на телефоне.

```bash
npm install
npm start
```

Отсканируйте QR-код из терминала в Expo Go. Телефон и компьютер должны быть в одной сети.

Версия Expo Go должна поддерживать Expo SDK 58. Если приложение не откроется, соберите установочный файл через [EAS Build](https://docs.expo.dev/build/introduction/):

```bash
npx eas-cli@latest build --platform android
```

## Проверки

